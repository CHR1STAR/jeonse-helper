# 전세계약 도우미

전월세 계약이 처음인 사람이 매물을 비교하고, 계약 준비부터 계약 후 할 일까지 차근차근 확인하는 모바일 웹앱입니다.

## 실행 방법

비회원 기능은 `index.html`을 브라우저에서 열어 살펴볼 수 있습니다. **비회원으로 계속하기 → 확인 → 매물 등록** 순서로 진행하세요. 사진 파일은 `index.html`과 같은 폴더에 둡니다. 로그인은 HTTP 또는 HTTPS 주소에서 실행하고 [로그인 설정](login-setup.md)을 완료해야 합니다.

## 시연 순서

1. 집 이름, 계약 유형, 보증금 등을 한 질문씩 입력해 후보를 등록합니다. 모르는 항목은 건너뛸 수 있습니다.
2. 후보 목록에서 집을 골라 수압, 누수, 벌레 등 방문 체크리스트를 기록합니다. 결과와 메모는 매물별로 저장됩니다.
3. **이 집으로 계약할게요**를 눌러 계약 전 질문을 진행합니다. 화면을 나갔다 돌아오면 저장한 단계에서 이어갈 수 있습니다.
4. 계약을 완료하고 계약 후 할 일을 확인합니다. 계약 준비 중에는 등기사항증명서 사진에서 주요 용어를 찾는 한글 OCR 기능도 시연할 수 있습니다. OCR 모델 파일 다운로드에는 인터넷 연결이 필요합니다.

## 저장 구조 및 제출 점검

비회원 기록은 브라우저에 저장됩니다. 로그인 상태에서는 Supabase의 `jeonse_workspaces`에 매물과 진행 상태를 계정별로 저장하도록 구성했습니다. [SQL 파일](jeonse-supabase.sql)은 앱의 작업 공간 테이블을 만들고 본인 기록에만 접근하도록 설정합니다.

| 항목 | 현재 상태 |
| --- | --- |
| 매물 입력과 목록 | 구현. 비회원 시연 가능 |
| 계정 로그인과 기록 동기화 | Google·이메일 로그인 코드와 SQL 포함. 공급자 설정과 실제 로그인 검증 필요 |
| 앱 데이터 테이블 간 관계 | 앱 데이터는 현재 테이블 하나의 JSON으로 저장. 과제의 관계형 테이블 조건은 별도 확인 및 보완 필요 |
| Docker, 자동 테스트, CI | 추가 필요 |
| 웹앱 배포 주소, 블로그 주소 | 최종 제출 시 기재 |
